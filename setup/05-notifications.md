# ORI Notifications Setup Guide

This guide walks through creating two essential notifications for the Operational Risk Intelligence application.

---

## Notification 1: ORI - Recommendation Pending Review

### Steps to Create in ServiceNow

1. Navigate to **System Notification > Email > Notifications**
2. Click **New**
3. Configure as follows:

| Field | Value |
|-------|-------|
| **Name** | ORI - Recommendation Pending Review |
| **Table** | x_ori_ai_recommendation |
| **Send when** | Inserted |
| **Condition** | current.state == 'pending' |
| **Active** | true |

### Recipients Configuration

#### For PDI Testing (Development):
- In the **Who should get notified** section, click the hamburger menu
- Select **Specific person**
- Add your own user account (e.g., admin or your assigned ServiceNow dev user)
- This ensures you receive test notifications during development

#### For Production:
- Instead of a specific user, use **Group**
- Select the group stored in the system property: `x_ori.reviewer_group`
- To verify this property exists:
  1. Navigate to **System Properties > Properties**
  2. Search for `x_ori.reviewer_group`
  3. Confirm it points to your designated reviewer group (e.g., "Risk Analysts")
  4. If it doesn't exist, create it with the group name

### Email Template

**Subject:**
```
[ORI] New Risk Pattern Detected — ${pattern_summary} (${severity})
```

**Body:**
Paste the following text exactly into the notification body field:

```
A recurring operational risk pattern has been detected.

Pattern: ${pattern_summary}
Severity: ${severity}
Confidence: ${confidence_score}

Root Cause Hypothesis:
${root_cause_hypothesis}

Recommendation:
${recommendation_text}

Proposed Problem Statement:
${problem_statement}

Review and approve or reject this recommendation:
${URI}

Generated by Operational Risk Intelligence.
```

## Notification 2: ORI - Monthly Run Summary (Event-Driven)

This notification fires when a monthly analysis completes using a custom event.

### Step 1: Register the Custom Event

1. Navigate to **System Policy > Events > Registry**
2. Click **New**
3. Configure as follows:

| Field | Value |
|-------|-------|
| **Name** | x_ori.analysis.complete |
| **Table** | x_ori_analysis_run |
| **Application** | x_ori (Operational Risk Intelligence) |

4. Click **Submit**

This event will be fired by the scheduled job or workflow when monthly analysis completes.

### Step 2: Create the Notification

1. Navigate to **System Notification > Email > Notifications**
2. Click **New**
3. Configure as follows:

| Field | Value |
|-------|-------|
| **Name** | ORI - Monthly Run Summary |
| **Table** | x_ori_analysis_run |
| **Send when** | Event fired |
| **Event name** | x_ori.analysis.complete |
| **Active** | true |

### Recipient Configuration

- Use **Specific people** for testing, or **Group** for production
- For production, use the same `x_ori.reviewer_group` system property

### Email Template

**Subject:**
```
[ORI] Monthly Analysis Complete — ${status} | ${recommendations_generated} recommendations
```

**Body:**
Paste the following text exactly into the notification body field:

```
Operational Risk Intelligence — Monthly Analysis Summary

Status:                    ${status}
Run Date:                  ${run_date}
Incidents Analyzed:        ${incidents_analyzed}
Incidents Excluded:        ${incidents_excluded} (${noise_filter_summary})
Clusters Found:            ${clusters_found}
Recommendations Generated: ${recommendations_generated}

${error_log}

View the full run record: ${URI}
```

## Verification

After creating both notifications:

1. **For Notification 1**: Create a test recommendation record in `x_ori_ai_recommendation` and set state to 'pending'
   - You should receive the email within seconds
   - Check the **System Notification > Email > Outgoing** queue to verify it was sent

2. **For Notification 2**: Trigger the `x_ori.analysis.complete` event from your analysis engine
   - The notification should fire for that `x_ori_analysis_run` record
   - Verify in **System Notification > Email > Outgoing**

---

## Troubleshooting

- **Email not received**: Check spam folder or verify recipient address in the notification record
- **Event not firing**: Confirm the event name matches exactly: `x_ori.analysis.complete`
- **Variables not populated**: Ensure the referenced fields exist on the respective tables with exact field names
- **System Property Missing**: If `x_ori.reviewer_group` doesn't exist, create it manually or programmatically during app initialization
